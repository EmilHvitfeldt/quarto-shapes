# Changelog

All notable changes to quarto-shapes are documented here.

## Unreleased

## 0.2.0

### Added

- `direction=` attribute to point a callout's tail any way: a compass angle in degrees (e.g. `45`, `135`, `225`, where 0 is up and angles increase clockwise) or the keywords `up`/`right`/`down`/`left`. Applies to `.shape-callout-round`, `.shape-callout-oval`, `.shape-callout-rounded`, and `.shape-speech-bubble`.
